Windows PC에 연결이 안 돼요
  1. PC에서 설정 → 시스템 → 원격 데스크톱을 켭니다. (Windows Pro·Enterprise에만 있습니다. Home은 아래 질문을 보세요.)
  2. 폰과 PC가 같은 Wi-Fi인지 확인합니다. 집 밖이라면 "집 밖에서 접속하려면"을 보세요.
  3. 아이디는 PC에 로그인하는 계정입니다. Microsoft 계정이면 이메일 주소와 그 비밀번호(PIN 아님)를 넣습니다.
  4. PC가 절전 중이면 깨운 뒤 다시 시도합니다(보관함 ⋮ → 켜기, Wake-on-LAN 설정 시).
I can't connect to my Windows PC
  1. On the PC, turn on Settings → System → Remote Desktop (Windows Pro/Enterprise only; for Home see below).
  2. Make sure the phone and the PC are on the same Wi-Fi. Away from home, see "Connecting from outside".
  3. The user name is the account you sign in to the PC with. For a Microsoft account, use the e-mail address and its password (not the PIN).
  4. If the PC is asleep, wake it and try again (vault ⋮ → Wake, when Wake-on-LAN is set up).
Windows PC に接続できません
  1. PC で設定 → システム → リモート デスクトップをオンにします (Windows Pro/Enterpriseのみ。Home については以下をご覧ください)。
  2. スマホと PC が同じ Wi-Fiにあることを確認してください。外出先の場合は「外出先から接続するには」をご覧ください。
  3. ユーザー名は PC へのログインに使用するアカウントです。Microsoft アカウントの場合は、メールアドレスとそのパスワード (PIN ではありません) を入力します。
  4. PC がスリープ状態の場合は、復帰させてからもう一度お試しください (保管庫 ⋮ → 起動、Wake-on-LAN 設定時)。
无法连接到 Windows PC
  1. 在电脑上开启设置 → 系统 → 远程桌面（仅限 Windows Pro/Enterprise；Home 版请参见下方）。
  2. 请确保手机和电脑连接至同一 Wi-Fi。如果在外面，请参见“在外连接”。
  3. 用户名是你在电脑上登录所用的账号。如果是 Microsoft 账号，请输入邮箱地址及其密码（不是 PIN 码）。
  4. 如果电脑处于睡眠状态，请唤醒后再试（设置了 Wake-on-LAN 时，保管库 ⋮ → 唤醒）。
집 밖에서 접속하려면

집 PC에 Deskify PC판을 설치하고 같은 구글 계정으로 로그인해 두면, 밖에서도 그 PC를 거쳐 연결됩니다(공유기 설정 필요 없음). 직접 연결하려면 공유기에서 포트 포워딩과 DDNS를 설정할 수도 있습니다.

Connecting from outside

Install Deskify for Windows on the home PC and sign in with the same Google account: away from home the phone connects through it (no router setup). You can also set up port forwarding and DDNS on your router for a direct connection.

外出先から接続するには

自宅の PC にDeskify Windows 版をインストールして同じ Google アカウントでログインしておけば、外出先からでもその PC を経由して接続できます (ルーター設定は不要)。直接接続したい場合は、ルーターでポートフォワーディングと DDNS を設定することもできます。

在外连接

在家里电脑上安装 Deskify Windows 版并登录相同的 Google 账号：在外面时手机可通过该电脑中转连接（无需设置路由器）。若想直接连接，也可以在路由器上设置端口转发和 DDNS。

Windows Home이라 원격 데스크톱이 없어요

Windows Home은 원격 데스크톱으로 접속받을 수 없습니다. VNC를 쓰세요: PC에 TightVNC나 UltraVNC 같은 VNC 서버를 설치하고 비밀번호를 정한 뒤, Deskify에서 컴퓨터 추가 → VNC로 추가합니다.

My PC runs Windows Home (no Remote Desktop)

Windows Home can't accept Remote Desktop connections. Use VNC: install a VNC server such as TightVNC or UltraVNC on the PC, set a password, then add the computer in Deskify as VNC.

Windows Home のためリモート デスクトップがありません

Windows Home はリモート デスクトップ接続を受け付けることができません。VNCをご利用ください: PC に TightVNC や UltraVNC などの VNC サーバーをインストールしてパスワードを設定し、Deskify でコンピューターを追加 → VNCとして追加します。

电脑是 Windows Home 版（没有远程桌面）

Windows Home 版无法接收远程桌面连接。请使用 VNC：在电脑上安装 TightVNC 或 UltraVNC 等 VNC 服务器并设置密码，然后在 Deskify 中选择添加电脑 → VNC 进行添加。

Mac에 연결하려면

Mac에서 시스템 설정 → 일반 → 공유 → 화면 공유를 켭니다. Deskify에서 컴퓨터 추가 → VNC, 운영체제 Mac을 고르고 Mac의 사용자 이름과 비밀번호를 넣습니다.

Connecting to a Mac

On the Mac, turn on System Settings → General → Sharing → Screen Sharing. In Deskify add a computer as VNC, pick Mac, and enter the Mac's user name and password.

Mac に接続するには

Mac でシステム設定 → 一般 → 共有 → 画面共有をオンにします。Deskify でコンピューターを追加 → VNCを選択し、OS に Mac を選んで、Mac のユーザー名とパスワードを入力します。

连接到 Mac

在 Mac 上开启系统设置 → 通用 → 共享 → 屏幕共享。在 Deskify 中选择添加电脑 → VNC，操作系统选择 Mac，并输入 Mac 的用户名和密码。

리눅스·라즈베리파이·NAS

터미널은 SSH(포트 22)로, 화면은 VNC로 연결합니다. RealVNC Server는 옵션 → 보안에서 인증을 "VNC 비밀번호", 암호화를 "선호 해제"로 바꿔야 연결됩니다.

SSH를 비밀번호 없이 쓰려면 컴퓨터 편집 화면에서 키 만들기 → 서버에 등록을 누르세요. 다음부터 키로 바로 접속합니다.

Linux, Raspberry Pi, NAS

Use SSH (port 22) for a terminal and VNC for the screen. RealVNC Server needs Options → Security: Authentication "VNC password", Encryption "Prefer off".

For SSH without a password, press Make a key → Add to server in the computer's editor; from then on the key logs in.

Linux、Raspberry Pi、NAS

ターミナルはSSH (ポート 22)、画面はVNCで接続します。RealVNC Server はオプション → セキュリティで、認証を「VNC パスワード」、暗号化を「オフを優先」に変更する必要があります。

パスワードなしで SSH を使用するには、コンピューターの編集画面でキー作成 → サーバーに登録を押してください。次回以降はキーでそのままログインできます。

Linux、Raspberry Pi、NAS

终端使用 SSH（端口 22）连接，画面使用 VNC 连接。RealVNC Server 需要在选项 → 安全中将身份验证设为“VNC 密码”，加密设为“优先关闭”才能连接。

如需免密码使用 SSH，请在电脑编辑界面中点击创建密钥 → 添加到服务器，之后即可直接使用密钥登录。

한글 입력은 어떻게 하나요

원격 PC의 한/영 전환을 그대로 씁니다. 실물 키보드는 한/영 키, 화면 키보드는 자판 위 키 막대의 한/영 키를 누르세요. 글자는 원격 PC의 입력기가 조합합니다.

Typing Korean (or another IME)

Use the remote PC's own input switching: the Han/Eng key on a keyboard, or the key bar above the on-screen keyboard. The remote PC's IME composes the characters.

日本語などの入力 (IME)

リモート PC 側の入力切り替えをそのまま使います。文字の変換はリモート PC の IME が行います。韓国語入力の 한/영 キーは、画面キーボード上部のキーバーにもあります。

输入中文等（输入法）

直接使用远程电脑自己的输入法切换，文字由远程电脑的输入法组字。韩文输入的 한/영 键也在屏幕键盘上方的按键栏中。

파일 주고받기
  • 보내기: 폰 ↔ Deskify PC판 사이에 파일을 바로 보냅니다(집 밖에서도).
  • 원격 데스크톱 안에서: 폰 저장소가 원격 PC에 드라이브로 보입니다(Pro).
  • SSH 서버: 세션 화면의 파일(SFTP)로 올리고 받습니다.
Moving files
  • Send: straight between the phone and Deskify for Windows (also from outside).
  • Inside Remote Desktop: the phone's storage shows up as a drive on the remote PC (Pro).
  • SSH servers: the session's Files (SFTP).
ファイルの転送
  • 送信: スマホと Deskify Windows 版の間で直接ファイルを送ります (外出先からでも)。
  • リモート デスクトップ内: スマホのストレージがリモート PC にドライブとして表示されます (Pro)。
  • SSH サーバー: セッション画面のファイル (SFTP) でアップロード・ダウンロードします。
文件传输
  • 发送：手机与 Deskify Windows 版之间直接发送文件（在外也可以）。
  • 在远程桌面内：手机存储在远程电脑上显示为驱动器（Pro）。
  • SSH 服务器：在会话界面的文件（SFTP）中上传和下载。
무료와 Pro는 무엇이 다른가요

무료: 저장 컴퓨터 3대, 동시 세션 1개, 하루 보내기 3번, OTP 2개, 광고. Pro: 모두 무제한, 기기 간 동기화, 광고 없음, 폰·태블릿·PC가 한 계정으로 함께 풀립니다. 평생 이용권은 앱 기능(폰 앱 전부·PC판 Pro·광고 없음·보조 기기 1대)을 평생 쓰고, 서버를 쓰는 동기화·웹 원격·웹판·중계·원격 지원 도와주기는 클라우드 구독(월 ₩1,900 / 연 ₩19,000)을 더해 씁니다. 가입하면 7일 동안 Pro를 무료로 써 볼 수 있습니다.

Free vs Pro

Free: 3 saved computers, 1 session at a time, 3 sends a day, 2 OTP codes, ads. Pro: no limits, sync between devices, no ads; phone, tablet and PC unlock with one account. The lifetime licence keeps the app's features for good (every phone feature, PC Pro, no ads, one companion device); the server ones — sync, web remote, web Deskify, relays and helping with remote support — come with the Cloud subscription (₩1,900 a month / ₩19,000 a year). New accounts get Pro free for 7 days.

無料と Pro の違い

無料: 保存できるコンピューター 3 台、同時セッション 1 つ、1 日の送信 3 回、OTP 2 つ、広告あり。Pro: すべて無制限、端末間の同期、広告なし、スマホ・タブレット・PC が 1 つのアカウントでまとめてアンロックされます。買い切りはアプリ機能 (すべてのスマホ機能、PC 版 Pro、広告なし、サブ端末 1 台) をずっと利用でき、サーバーを使用する同期、Web リモート、Web 版 Deskify、中継、リモートサポートでの手伝いはクラウド購読 (月額 ₩1,900 / 年額 ₩19,000) を追加して利用します。新規登録すると、7 日間 Pro を無料でお試しいただけます。

免费版与 Pro 的区别

免费：保存 3 台电脑，同时运行 1 个会话，每天发送 3 次，2 个 OTP 验证码，有广告。Pro：全部无限制，设备间同步，无广告；手机、平板和电脑通用一个账号解锁。终身版可永久使用应用功能（全部手机功能、电脑版 Pro、无广告、1 台辅助设备）；使用服务器的同步、网页远程、网页版 Deskify、中继以及提供远程协助，则需另外搭配云订阅（每月 ₩1,900 / 每年 ₩19,000）。注册即可免费试用 Pro 7 天。

구독 해지·환불

Google Play에서 결제했다면 Play 스토어 → 결제 및 정기 결제에서 해지합니다. 웹에서 결제했다면 Paddle 영수증 이메일의 링크에서 해지·환불을 요청합니다(환불 정책). 해지해도 저장한 컴퓨터·키·OTP는 지워지지 않고, Pro 기능만 잠깁니다.

Cancelling and refunds

Bought on Google Play: cancel in Play Store → Payments & subscriptions. Bought on the web: use the link in Paddle's receipt e-mail (refund policy). Cancelling deletes nothing: your computers, keys and OTP codes stay; only the Pro features lock.

解約・返金

Google Play で購入した場合: Play ストア → お支払いと定期購入から解約します。Web で購入した場合: Paddle の領収書メールにあるリンクから解約・返金をリクエストします (返金ポリシー)。解約しても保存したコンピューター、キー、OTP コードは削除されず、Pro 機能のみがロックされます。

取消订阅与退款

在 Google Play 购买：在 Play 商店 → 付款和订阅中取消。在网页上购买：请使用 Paddle 收据邮件中的链接申请退订或退款（退款政策）。取消订阅不会删除任何内容：你保存的电脑、密钥和 OTP 验证码都会保留，仅锁定 Pro 功能。

비밀번호는 안전한가요

저장한 비밀번호와 키는 기기 안에 암호화해 보관합니다. 동기화를 켜면 보관함은 암호화된 상태로만 서버에 올라갑니다. 앱 잠금(지문·얼굴)과 컴퓨터별 "연결할 때 인증"도 켤 수 있습니다.

Are my passwords safe?

Saved passwords and keys are encrypted on the device. With sync on, the vault goes to the server only encrypted. You can also turn on the app lock (fingerprint/face) and "authenticate to connect" per computer.

パスワードは安全ですか？

保存されたパスワードとキーは端末内で暗号化して保管されます。同期をオンにすると、保管庫は暗号化された状態でのみサーバーに送信されます。アプリロック (指紋/顔) や、コンピューターごとの「接続時に認証」を有効にすることもできます。

我的密码安全吗？

保存的密码和密钥均在设备本地加密保存。开启同步后，保管库也仅在加密状态下上传至服务器。你还可以开启应用锁（指纹/面部识别）以及针对每台电脑的“连接时验证”。

웹에서 쓰기(deskify-app.com/web.html)에서 아래 둘과 원격 지원 가운데 하나를 고릅니다. 구글로 한 번 로그인하면 같은 브라우저의 다른 페이지에서도 로그인된 채로 열립니다.

웹 원격deskify-app.com/remote.html

브라우저에서 내 PC의 실제 화면을 보고 마우스·키보드로 조작합니다. 원격 데스크톱(RDP)이 없는 Windows Home PC도 됩니다. 소리, 클립보드, 파일 보내기도 됩니다.

웹판 Deskifydeskify-app.com/app.html

PC판 보관함의 컴퓨터 목록을 브라우저에서 열고, 그 PC를 거쳐 SSH 터미널·파일(SFTP)·원격 데스크톱·VNC에 접속합니다. 비밀번호와 키는 브라우저로 가지 않고 PC가 대신 접속합니다. PC 화면에는 아무것도 뜨지 않습니다.

원격 지원deskify-app.com/support.html

다른 사람의 Windows PC를 9자리 번호로 돕습니다. 돕는 사람은 구독(Pro 구독 또는 클라우드 구독), 도움 받는 사람은 무료이고 설치·로그인이 필요 없습니다. 아래 원격 지원을 참고하십시오.

PC에서 켜기

  1. Deskify PC판에 로그인합니다.
  2. 설정 → 모바일 기기 → 화면 공유 원격 (Pro)에서 웹 원격은 "화면 공유 원격 허용 (브라우저·Deskify 앱)"을, 웹판은 "웹에서 내 컴퓨터 목록·원격 쓰기"를 켭니다. 필요한 것만 켜면 됩니다. 처음에는 둘 다 꺼져 있습니다.
  3. (선택) 잠금 화면·로그인 화면에서도 쓰려면 같은 곳의 "잠금 화면에서도 쓰기 (서비스 설치)"를 켭니다. 관리자 권한을 한 번 묻습니다.

브라우저에서 로그인

  • QR (공용 컴퓨터에 권장): 페이지에 뜬 QR을 폰 Deskify 보관함 위쪽의 QR 단추로 비춥니다. 브라우저 종류와 접속 위치를 확인한 뒤 PC를 고르고 허용합니다. QR을 비출 수 없으면 페이지의 코드를 폰에 입력합니다. 이렇게 들어온 브라우저는 페이지를 닫거나 12시간이 지나면 계정에서 자동으로 빠집니다.

  1. 주 기기(폰·태블릿): 설정 → 보조 기기 → 보조 기기 허용을 켭니다. Android 17에서 "근처 기기 권한 꺼짐"이 보이면 허용을 누릅니다.
  2. 주 기기가 PC판이면: Deskify PC판에 로그인한 뒤 설정 → 모바일 기기 → 보조 모니터 (Pro)에서 "폰을 원격 데스크톱의 두 번째 모니터로"를 켭니다.
  3. 주 기기에서 원격 컴퓨터에 RDP나 SSH로 연결합니다.
  4. 보조 기기(폰): Deskify 보관함의 보조 기기로 연결 카드를 누릅니다. 카드가 없으면 설정 → 보조 기기 → 맨 아래 "보조 기기로 연결"을 누릅니다.
  5. 목록에 나타난 주 기기의 이름을 누릅니다.
  6. 주 기기 화면에 6자리 코드가 뜹니다. 폰에 그 코드를 입력하고 페어링을 누릅니다.
  7. 주 기기의 세션을 고르고, 이 폰으로 할 역할을 고릅니다.
코드는 처음 한 번만 입력합니다. 페어링은 양쪽 모두에 저장되어, 다음에는 반대로 이 폰이 주 기기가 되어도 코드 없이 연결됩니다. 다음부터는 보관함의 카드를 누르면 바로 연결되고, 열린 세션이 하나면 지난번 역할로 바로 시작합니다.

역할

⌨️ 키보드 · 트랙패드RDP · SSH

태블릿 화면을 가리지 않고 폰으로 포인터와 키를 다룹니다. 한 손가락: 이동, 탭: 클릭, 두 손가락: 스크롤, 두 손가락 탭: 우클릭, 길게: 드래그. 아래 키 줄과 단축키 버튼으로 입력합니다. SSH에서는 화면의 프로그램(vim, tmux 등)이 마우스를 받으면 트랙패드가 됩니다.

🖥️ 보조 모니터RDP

원격 Windows에 폰 크기의 모니터가 하나 더 생깁니다. 창을 끌어다 폰 쪽으로 옮기면 됩니다. 탭: 클릭, 끌기: 스크롤, 길게: 우클릭. 뒤로 가기를 누르면 도구와 키 줄이 나타나고, 모니터 위치(오른쪽·왼쪽·아래·위)와 배율, "이 화면 크기로 모니터 다시 맞추기"를 고를 수 있습니다.

✏️ 그림 타블렛RDP

폰·태블릿의 펜으로 원격 PC에 그립니다. 필압·펜 버튼·지우개가 Windows 펜 입력으로 갑니다. 원격 데스크톱 전체가 패드에 대응하고, 패드에 데스크톱 축소 화면을 띄우거나 끌 수 있습니다. 펜이 없으면 손가락으로도 그립니다.

🖌️ 브러시 패드RDP

실행 취소·브러시 크기·지우개·화면 이동 같은 그림 프로그램 단축키를 큰 버튼으로 누릅니다. 버튼 순서를 바꾸거나 숨기고, 내 키 조합을 추가할 수 있습니다.

🔲 스트림덱RDP · SSH · PC판의 "이 PC"

내가 만든 큰 버튼 하나로 단축키·문장·명령·프로그램 실행을 한 번에 보냅니다. 여러 단계를 묶거나 폴더로 정리할 수 있고, PC판이 주 기기면 OBS 조작과 앞에 있는 프로그램에 맞춘 페이지 전환도 됩니다.

💡 세션 도우미SSH

명령어 도움말과 결과 보기를 폰에 띄웁니다. 고른 명령은 주 기기의 터미널로 들어갑니다.

📂 파일SSH

서버 폴더를 폰에서 봅니다. "터미널 따라가기"를 켜면 터미널의 cd를 따라갑니다. 누른 경로를 프롬프트에 넣거나 그 폴더로 cd할 수 있습니다.

🖥 두 번째 셸SSH

같은 SSH 연결에 셸을 하나 더 열어 폰에 보여 줍니다. 로그를 보면서 다른 명령을 칠 때 씁니다.

✨ AI 도우미SSH

터미널은 주 기기에 두고, 폰에서 AI에게 부탁합니다. 명령은 주 기기 터미널에서 실행됩니다. 주 기기의 설정 → 실험실에 Claude·Gemini 키가 있어야 합니다(키는 주 기기에만 있습니다).

🎮 PC 화면 스트리밍 (시험)PC판의 "이 PC"

Deskify PC판이 깔린 PC의 화면을 그래픽카드로 압축해 폰에서 보고, 폰 터치로 마우스를 움직입니다.

PC판이 주 기기일 때는 보조 모니터·스트림덱·PC 화면 스트리밍만 고를 수 있습니다.

역할 바꾸기 · 끝내기

  • 폰에서: 위쪽 띠의 역할 이름(⇄)을 누르면 다른 역할로 바꿉니다. ←는 세션에서 나가고(연결은 유지), 보관함 카드의 연결 끊기로 완전히 끊습니다.
  • 주 기기에서: 세션 화면의 ⋮ → 보조 기기에서 연결된 폰마다 역할을 정해 줄 수 있습니다. 보조 모니터 위치도 여기서 바꿉니다.
  • 세션 넘기기: 주 기기의 ⋮ → 보조 기기에서 세션을 폰으로 넘기거나, 폰의 역할 목록 아래 "세션 가져오기"로 가져옵니다. 비밀번호는 넘어가지 않아 받는 기기의 보관함 정보나 로그인 창을 씁니다. (PC판은 넘기기를 하지 않습니다.)

자주 생기는 문제

폰 목록에 주 기기가 보이지 않습니다
  • 두 기기가 정말 같은 Wi-Fi인지 확인합니다. 한쪽이 모바일 데이터나 다른 공유기면 보이지 않습니다.
  • 게스트 Wi-Fi나 공유기의 AP 격리(무선 기기 간 통신 차단)가 켜져 있으면 기기끼리 서로 볼 수 없습니다. 일반 Wi-Fi를 쓰거나 공유기 설정에서 끕니다. 회사·카페 Wi-Fi는 대부분 막혀 있습니다.
  • 폰이나 PC의 VPN을 끕니다. VPN은 같은 Wi-Fi의 기기를 찾는 신호를 막을 수 있습니다.
  • 주 기기에서 Deskify를 열어 두고 보조 기기 허용이 켜져 있는지 봅니다. 화면이 꺼져 절전 중인 기기는 응답하지 않습니다.
  • Android 17은 두 기기 모두 근처 기기 권한이 필요합니다.
  • 전에 페어링한 기기는 목록 아래 "이전에 페어링한 기기"를 누르면 마지막 주소로 연결합니다.
PC판이 주 기기인데 폰에서 찾지 못합니다
  • PC판에 로그인되어 있고 Pro인지, 설정 → 모바일 기기 → 보조 모니터가 켜져 있는지 확인합니다.
  • Windows 방화벽: 처음 실행할 때 뜬 창에서 Deskify의 개인 네트워크 접근을 허용해야 합니다. 거부했다면 Windows 보안 → 방화벽 → "방화벽에서 앱 허용"에서 Deskify를 켭니다.
  • Windows 네트워크 프로필이 공용이면 막힐 수 있습니다. 설정 → 네트워크 및 인터넷에서 개인으로 바꿉니다.
  • PC의 VPN을 끕니다.
코드가 틀렸다고 나오거나 코드 창이 사라졌습니다
  • 코드는 주 기기에 지금 떠 있는 6자리입니다. 3번 틀리면 연결이 끊깁니다.
  • 코드는 한 번 쓰고 버립니다. 주 기기에서 취소했거나 연결이 끊겨 코드 창이 닫혔다면, 폰에서 주 기기를 다시 눌러 새 코드를 받습니다.
  • "다른 기기와 페어링 중"이면 다른 폰의 페어링이 끝난 뒤 다시 합니다.
"자리 없음"이 나옵니다

주 기기가 받을 수 있는 대수를 다 썼습니다(구독 2대, 평생권·광고 1대, PC판 2대). 주 기기의 설정 → 보조 기기(PC판은 설정 → 모바일 기기)에서 안 쓰는 기기를 삭제합니다.

보조 모니터가 생기지 않습니다
  • 원격 Windows가 세션 중 화면 크기 바꾸기(디스플레이 제어)를 지원해야 합니다. Windows 8.1·Server 2012 R2 이후 버전에서 됩니다.
  • 원격 PC의 그룹 정책에서 "최대 모니터 수 제한"이 1이면 모니터를 추가할 수 없습니다.
  • 보조 모니터는 데스크톱 하나에 1대입니다. 다른 폰이나 DeX 화면이 이미 쓰고 있으면 그쪽을 끕니다.
  • PC판은 Deskify PC판 안에서 연결한 원격 데스크톱 탭에서만 됩니다(Windows 기본 원격 데스크톱 창은 안 됩니다).
  • 여전히 안 되면 폰에서 뒤로 가기 → "이 화면 크기로 모니터 다시 맞추기"를 누르거나 역할을 다시 고릅니다.
키나 터치가 들어가지 않고 "잠시 멈췄습니다"가 보입니다

키보드·보조 모니터·그림 타블렛·스트림덱 같은 입력 역할은 주 기기가 그 세션을 화면에 띄우고 있을 때만 동작합니다. 보이지 않는 PC에 잘못 입력되지 않게 막는 것입니다. 주 기기에서 그 세션을 열면 이어집니다. 주 기기의 앱 잠금이 걸려 있을 때도 멈춥니다.

"도움을 꺼 두었습니다" / "보안 연결 실패"
  • 주 기기의 설정 → 보조 기기 → 페어링한 기기에서 그 기기의 "이 기기가 내 세션을 돕게 허용"을 켭니다.
  • 보안 연결(악수)에 실패하면 주 기기에서 보조 기기 허용을 껐다 켠 뒤 다시 시도합니다.
화면이 끊기거나 흐립니다

보조 모니터 화면은 Wi-Fi로 전송되며, 바쁠 때는 화질과 빈도를 자동으로 낮춥니다(최대 약 1.5MB/s). 공유기 가까이에서 5GHz Wi-Fi를 쓰면 좋아집니다. 연결이 잠깐 끊기면 최대 5분까지 자동으로 다시 연결합니다.

한계

  • 같은 Wi-Fi(같은 네트워크)에서만 됩니다. 인터넷 너머의 기기는 보조 기기로 쓸 수 없습니다.
  • RDP와 SSH 세션에서 됩니다. VNC 세션은 지원하지 않습니다.
  • 보조 모니터는 데스크톱 하나에 1대입니다.
  • PC판이 주 기기면 보조 모니터·스트림덱·PC 화면 스트리밍만 됩니다. 보조 모니터 위치는 오른쪽이나 아래입니다.
  • 파일·두 번째 셸·AI 도우미는 주 기기가 다른 화면을 보여 줘도 계속 동작하지만, 입력 역할은 멈춥니다.

📱 Companion devices

Use a spare phone or tablet as a tool for the remote session you're working in: a trackpad, keyboard, second screen, drawing tablet and more.

Only the main device (the one that opened the session) connects to the remote computer. The companion talks only to the main device over the same Wi-Fi, and no password ever goes to it.

What you need

  • Both devices on the same Wi-Fi (the same router).
  • Deskify installed on both.
  • The main device is Deskify on a phone or tablet, or Deskify for Windows. It needs a connected session to a remote computer before you can pick a role.
  • Allowing companions is a Pro feature of the main device: two at once with the subscription (and the 7-day trial), one with the lifetime licence. On the free edition, watching an ad in Settings → Pro opens one for 3 hours. The companion itself needs nothing.

Connecting the first time (once)

  1. Main device (phone/tablet): turn on Settings → Companion devices → Allow companion devices. On Android 17, if "Nearby devices" is off, tap Allow.
  2. If the main device is the PC app: sign in to Deskify for Windows, then turn on "The phone as a second monitor of a remote desktop" in Settings → Mobile devices → Second monitor (Pro).
  3. On the main device, connect to a remote computer over RDP or SSH.
  4. Companion (phone): tap the Connect as a companion card in the Deskify vault. No card? Use Settings → Companion devices → "Connect as a companion" at the bottom.
  5. Tap the main device's name in the list.
  6. A 6-digit code appears on the main device. Type it on the phone and tap Pair.
  7. Pick one of the main device's sessions, then a role for this phone.
You type the code only once. The pairing is saved on both sides, so next time either device can be the main one without a code. After that, tapping the vault card connects straight away, and with one open session it starts in the role you used last.

Roles

⌨️ Keyboard · trackpadRDP · SSH

Move the pointer and type from the phone without covering the tablet. One finger: move, tap: click, two fingers: scroll, two-finger tap: right-click, hold: drag. Type with the key bar and shortcut buttons. Over SSH it becomes a trackpad when the program on screen (vim, tmux…) takes the mouse.

🖥️ Second screenRDP

Windows gets one more monitor the size of the phone; drag windows over to it. Tap: click, drag: scroll, hold: right-click. Press Back for the tools and key bar: the monitor's side (right, left, below, above), its scale, and "Resize the monitor to this screen".

✏️ Drawing tabletRDP

Draw on the remote PC with the device's pen. Pressure, the pen button and the eraser arrive as Windows pen input. The whole desktop maps to the pad, with a small picture of it on the pad (or a plain pad). Without a pen, fingers draw.

🖌️ Brush padRDP

Drawing-program shortcuts as big buttons: undo, brush size, eraser, pan. Reorder or hide them and add your own key combinations.

🔲 Stream deckRDP · SSH · "This PC" on the PC app

One big button of your own sends a shortcut, text, a command or starts a program. Chain steps or group buttons in folders. With the PC app as the main device it also drives OBS and turns to the page of the program in front.

💡 Session helperSSH

Command help and the result view on the phone; the command you pick goes into the main device's terminal.

📂 FilesSSH

The server's folders on the phone. "Follow terminal" tracks the terminal's cd. Insert a path at the prompt or cd there.

🖥 Second shellSSH

Another shell on the same SSH connection, shown on the phone: watch a log while you type elsewhere.

✨ AI helperSSH

Keep the terminal on the main device and ask the AI from the phone; commands run in the main device's terminal. Needs a Claude or Gemini key in the main device's Settings → Labs (the key stays there).

🎮 PC screen streaming (beta)"This PC" on the PC app

The screen of the PC running Deskify for Windows, compressed by its graphics card, on the phone; touches move its mouse.

With the PC app as the main device, only Second screen, Stream deck and PC screen streaming are offered.

Switching roles · leaving

  • On the phone: tap the role name (⇄) in the strip at the top to switch. ← leaves the session (the link stays); disconnect from the vault card to end it.
  • On the main device: the session's ⋮ → Companion devices gives each connected phone a role and sets the second monitor's side.
  • Handing over: send the session to the phone from ⋮ → Companion devices, or take it with "Take the session over" under the phone's role list. No password moves: the receiving device uses its own vault or a sign-in prompt. (The PC app doesn't hand sessions over.)

Common problems

The main device doesn't show up on the phone
  • Check both are really on the same Wi-Fi; mobile data or another router won't do.
  • Guest Wi-Fi or the router's AP / client isolation stops devices from seeing each other. Use the main Wi-Fi or turn isolation off. Office and café Wi-Fi usually blocks it.
  • Turn off VPNs on the phone and the PC; they can block local discovery.
  • Keep Deskify open on the main device with companions allowed. A device asleep with its screen off doesn't answer.
  • Android 17 needs the Nearby devices permission on both.
  • A device paired before: tap it under "Paired before" to connect at its last address.
The PC app is the main device but the phone can't find it
  • Check you're signed in with Pro and Settings → Mobile devices → Second monitor is on.
  • Windows Firewall: allow Deskify on private networks in the prompt shown the first time. If you declined, turn Deskify on in Windows Security → Firewall → "Allow an app through firewall".
  • A Public network profile can block it; switch it to Private in Settings → Network & internet.
  • Turn off the PC's VPN.
The code is wrong or the code window is gone
  • Use the 6 digits showing on the main device now. Three wrong tries end the connection.
  • A code is used once. If it was cancelled on the main device or the link dropped, tap the main device on the phone again for a new code.
  • "Pairing with another device": wait until the other phone is done.
"No room"

The main device has all the companions it takes (subscription 2, lifetime or ad 1, PC app 2). Remove one you don't use in the main device's Settings → Companion devices (PC app: Settings → Mobile devices).

The second screen doesn't appear
  • The remote Windows must support resizing during a session (Display Control): Windows 8.1 / Server 2012 R2 or later.
  • A group policy limiting the number of monitors to 1 on the remote PC blocks it.
  • One second screen per desktop. If another phone or the DeX screen has it, turn that off.
  • On the PC, only remote desktop tabs inside Deskify for Windows can do it (not Windows' own Remote Desktop window).
  • Still nothing: press Back on the phone → "Resize the monitor to this screen", or pick the role again.
Keys or touches do nothing and it says "Paused"

Input roles (keyboard, second screen, drawing tablet, stream deck…) work only while the main device shows that session, so nothing goes to a PC you can't see. Open the session on the main device to continue. They also pause while the main device's app lock is on.

"Help turned off" / "Secure connection failed"
  • On the main device, Settings → Companion devices → Paired devices: turn on "May help with my sessions" for it.
  • If the secure handshake fails, turn Allow companion devices off and on again on the main device, then retry.
The picture stutters or looks blurry

The second screen streams over Wi-Fi and lowers quality and frame rate when busy (about 1.5 MB/s at most). 5 GHz Wi-Fi close to the router helps. A dropped link reconnects by itself for up to 5 minutes.

Limits

  • Same Wi-Fi (same network) only; a device across the internet can't be a companion.
  • RDP and SSH sessions. VNC sessions aren't supported.
  • One second screen per desktop.
  • With the PC app as the main device: Second screen, Stream deck and PC screen streaming only; the second monitor goes to the right or below.
  • Files, the second shell and the AI helper keep working while the main device shows something else; input roles pause.

📱 サブ端末

余っているスマホやタブレットを、作業中のリモートセッションのトラックパッド、キーボード、サブモニター、ペンタブレットなどのツールとして使います。

リモートコンピューターにはメイン端末（セッションを開いた端末）のみが接続します。サブ端末は同じ Wi-Fi 内でメイン端末とのみ通信し、パスワードがサブ端末に送信されることはありません。

必要なもの

  • 両方の端末が同じ Wi-Fi（同じルーター）に接続されている必要があります。
  • 両方の端末に Deskify がインストールされている必要があります。
  • メイン端末はスマホ・タブレットの Deskify、または Deskify PC 版（Windows）です。役割を選択するには、メイン端末でリモートコンピューターに接続されたセッションがある必要があります。
  • サブ端末の許可はメイン端末側の Pro 機能です。サブスク（7 日間の無料トライアルを含む）では同時に 2 台、買い切りでは 1 台まで接続できます。無料版では、設定 → Pro で広告を見ると 3 時間 1 台利用できます。サブ端末側は無料で利用できます。

初回接続（一度のみ）

  1. メイン端末（スマホ・タブレット）：設定 → サブ端末 → サブ端末を許可をオンにします。Android 17 で「付近のデバイスの権限がオフ」と表示された場合は「許可」をタップします。
  2. メイン端末が PC 版の場合：Deskify PC 版にログイン後、設定 → モバイル端末 → サブモニター (Pro) で「スマホをリモート デスクトップのセカンド モニターにする」をオンにします。
  3. メイン端末からリモートコンピューターに RDP または SSH で接続します。
  4. サブ端末（スマホ）：Deskify 保管庫のサブ端末として接続カードをタップします。カードがない場合は、設定 → サブ端末 → 一番下の「サブ端末として接続」をタップします。
  5. 一覧に表示されたメイン端末の名前をタップします。
  6. メイン端末に 6 桁のコードが表示されます。スマホにそのコードを入力し、ペアリングをタップします。
  7. メイン端末のセッションを選択し、このスマホで使う役割を選択します。
コードの入力は初回の一度のみです。ペアリング情報は双方に保存されるため、次回からはどちらの端末がメインになってもコードなしで接続できます。次回以降は保管庫のカードをタップするだけで直接接続され、開いているセッションが 1 つだけの場合は前回使用した役割ですぐに開始されます。

役割

⌨️ キーボード · トラックパッドRDP · SSH

タブレットの画面を遮ることなく、スマホでポインターの操作やキー入力を行えます。1 本指：移動、タップ：クリック、2 本指：スクロール、2 本指タップ：右クリック、長押し：ドラッグ。キーバーやショートカットボタンで入力します。SSH では画面上のプログラム（vim、tmux など）がマウスを受け付けるとトラックパッドになります。

🖥️ サブモニターRDP

リモートの Windows にスマホサイズのモニターがもう 1 台追加され、ウィンドウをドラッグして移動できます。タップ：クリック、ドラッグ：スクロール、長押し：右クリック。「戻る」を押すとツールやキーバーが表示され、モニターの位置（右・左・下・上）や倍率、「この画面サイズに合わせてモニターを再調整」を選択できます。

✏️ ペンタブレットRDP

端末のペンを使ってリモート PC に描画できます。筆圧、ペンボタン、消しゴムは Windows のペン入力として送信されます。デスクトップ全体がパッドに対応し、パッド上にデスクトップの縮小画面を表示したり非表示にしたりできます。ペンがない場合は指でも描けます。

🖌️ ブラシパッドRDP

元に戻す、ブラシサイズ、消しゴム、画面移動などのお絵描きソフトのショートカットを大きなボタンで操作できます。ボタンの並べ替えや非表示、独自のキーの組み合わせの追加も可能です。

🔲 ストリームデッキRDP · SSH · PC 版の「この PC」

自作した大きなボタン 1 つで、ショートカット、定型文、コマンドの送信やプログラムの起動を一括で行えます。複数のステップを組み合わせたりフォルダーで整理したりできるほか、PC 版がメイン端末の場合は OBS の操作や最前面のプログラムに応じたページ切り替えも行えます。

💡 セッションヘルパーSSH

コマンドのヘルプや実行結果をスマホに表示します。選択したコマンドはメイン端末のターミナルに入力されます。

📂 ファイルSSH

サーバーのフォルダーをスマホで閲覧できます。「ターミナルに追従」をオンにすると、ターミナルの cd に連動します。タップしたパスをプロンプトに入力したり、そのフォルダーへ cd したりできます。

🖥 2 つ目のシェルSSH

同じ SSH 接続上でもう 1 つのシェルを開いてスマホに表示します。ログを確認しながら別のコマンドを入力したいときに便利です。

✨ AI アシスタントSSH

ターミナルはメイン端末に置いたまま、スマホから AI に指示を出せます。コマンドはメイン端末のターミナルで実行されます。メイン端末の設定 → Labs に Claude または Gemini の API キーが必要です（キーはメイン端末にのみ保存されます）。

🎮 PC 画面ストリーミング (試験)PC 版の「この PC」

Deskify PC 版がインストールされた PC の画面をグラフィックカードで圧縮してスマホに表示し、スマホのタッチ操作でマウスを動かせます。

PC 版がメイン端末の場合、サブモニター、ストリームデッキ、PC 画面ストリーミングのみ選択できます。

役割の切り替え · 終了

  • スマホ側：上部バーの役割名（⇄）をタップすると別の役割に切り替わります。← でセッションから退出（接続は維持）し、完全に終了するには保管庫カードの「切断」をタップします。
  • メイン端末側：セッション画面の ⋮ → サブ端末 で、接続されているスマホごとに役割を設定できます。サブモニターの位置もここで変更します。
  • セッションの引き継ぎ：メイン端末の ⋮ → サブ端末 からセッションをスマホに引き継ぐか、スマホ側の役割一覧の下にある「セッションを引き継ぐ」で取得します。パスワードは転送されないため、受け取り側の端末の保管庫情報またはログイン画面を使用します。（PC 版では引き継ぎは行えません。）

よくあるトラブル

スマホのリストにメイン端末が表示されません
  • 両方の端末が本当に同じ Wi-Fi に接続されているか確認してください。片方がモバイルデータ通信や別のルーターの場合は検出されません。
  • ゲスト Wi-Fi やルーターの AP 分離（端末間通信の遮断）が有効になっていると、端末同士がお互いを検出できません。通常の Wi-Fi を使用するか、ルーターの設定で無効にしてください。会社やカフェの Wi-Fi では基本的に遮断されています。
  • スマホや PC の VPN をオフにしてください。VPN が同じ Wi-Fi 内の端末検出シグナルを遮断することがあります。
  • メイン端末で Deskify を開いたままにし、サブ端末の許可がオンになっているか確認してください。画面が消灯してスリープ中の端末は応答しません。
  • Android 17 では両方の端末で付近のデバイスの権限が必要です。
  • 以前ペアリングした端末は、リストの下の「以前にペアリングした端末」をタップすると最後の接続先アドレスで接続します。
PC 版がメイン端末なのにスマホから検出できません
  • PC 版にログイン済みで Pro であること、設定 → モバイル端末 → サブモニター がオンになっていることを確認してください。
  • Windows ファイアウォール：初回起動時の画面で Deskify のプライベート ネットワークへのアクセスを許可している必要があります。拒否した場合は、Windows セキュリティ → ファイアウォール →「ファイアウォールを介したアプリの許可」で Deskify を有効にしてください。
  • Windows のネットワーク プロファイルがパブリックになっているとブロックされる場合があります。設定 → ネットワークとインターネット でプライベートに変更してください。
  • PC の VPN をオフにしてください。
コードが間違っていると表示される、またはコード画面が消えました
  • コードはメイン端末に現在表示されている 6 桁の数字です。3 回間違えると接続が切断されます。
  • コードは一度しか使えません。メイン端末側でキャンセルされたか接続が切れてコード画面が閉じた場合は、スマホでもう一度メイン端末をタップして新しいコードを取得してください。
  • 「他の端末とペアリング中」と表示される場合は、他のスマホのペアリングが完了してからやり直してください。
「空きがありません」と表示されます

メイン端末が接続できる台数の上限に達しています（サブスクは 2 台、買い切り・広告は 1 台、PC 版は 2 台）。メイン端末の設定 → サブ端末（PC 版は 設定 → モバイル端末）で使用していない端末を削除してください。

サブモニターが表示されません
  • リモートの Windows がセッション中の画面サイズ変更（ディスプレイ制御）に対応している必要があります。Windows 8.1、Server 2012 R2 以降のバージョンで利用できます。
  • リモート PC のグループ ポリシーで「モニターの最大数を制限する」が 1 になっているとモニターを追加できません。
  • サブモニターは 1 つのデスクトップにつき 1 台までです。他のスマホや DeX 画面ですでに使用している場合は、そちらをオフにしてください。
  • PC 版では、Deskify PC 版の中で接続したリモート デスクトップのタブでのみ利用可能です（Windows 標準のリモート デスクトップ ウィンドウでは利用できません）。
  • それでも表示されない場合は、スマホで「戻る」→「この画面サイズに合わせてモニターを再調整」をタップするか、役割を選び直してください。
キーやタッチが効かず「一時停止中」と表示されます

キーボード、サブモニター、ペンタブレット、ストリームデッキなどの入力役割は、メイン端末の画面にそのセッションが表示されている間のみ動作します。画面が見えていない PC に誤入力されるのを防ぐためです。メイン端末でそのセッションを表示すると再開されます。また、メイン端末でアプリのロックがかかっている間も一時停止します。

「サポートが無効になっています」/「安全な接続に失敗しました」
  • メイン端末の 設定 → サブ端末 → ペアリング済み端末 で、その端末の「この端末が自分のセッションをサポートすることを許可」をオンにします。
  • 安全な接続（ハンドシェイク）に失敗した場合は、メイン端末で「サブ端末を許可」を一度オフにしてから再度オンにし、もう一度試してください。
画面が途切れる、またはぼやけて見えます

サブモニターの画面は Wi-Fi 経由で転送され、通信負荷が高いときは画質とフレームレートを自動的に下げます（最大約 1.5MB/s）。ルーターの近くで 5GHz Wi-Fi を使用すると改善されます。一時的に接続が切断された場合でも、最大 5 分間自動で再接続を試みます。

制限事項

  • 同じ Wi-Fi（同一ネットワーク）でのみ利用できます。インターネット越しの端末をサブ端末として使用することはできません。
  • RDP および SSH セッションで利用できます。VNC セッションには対応していません。
  • サブモニターは 1 つのデスクトップにつき 1 台までです。
  • PC 版がメイン端末の場合は、サブモニター、ストリームデッキ、PC 画面ストリーミングのみ利用できます。サブモニターの配置位置は右側または下側となります。
  • ファイル、2 つ目のシェル、AI アシスタントはメイン端末が他の画面を表示していても動作し続けますが、入力の役割は一時停止します。

📱 辅助设备

将闲置的手机或平板用作当前正在操作的远程会话的工具：触控板、键盘、副显示器、绘图板等。

只有主设备（打开会话的设备）会连接到远程电脑。辅助设备仅在同一 Wi-Fi 下与主设备通信，密码绝不会发送到辅助设备。

所需条件

  • 两台设备处于同一 Wi-Fi（同一路由器）下。
  • 两台设备均已安装 Deskify。
  • 主设备可以是手机/平板上的 Deskify，也可以是 Deskify 电脑版（Windows）。主设备上需要有已连接到远程电脑的活动会话，才能选择角色。
  • 允许辅助设备是主设备侧的 Pro 功能：订阅（含 7 天免费试用）可同时连接 2 台，终身版可连接 1 台。免费版在“设置 → Pro”中观看广告即可使用 1 台 3 小时。辅助设备本身完全免费。

首次连接（仅需一次）

  1. 主设备（手机/平板）：开启设置 → 辅助设备 → 允许辅助设备。在 Android 17 上，若提示“附近的设备权限已关闭”，请点击“允许”。
  2. 如果主设备是电脑版：登录 Deskify 电脑版后，在设置 → 移动设备 → 副显示器 (Pro)中开启“将手机作为远程桌面的第二台显示器”。
  3. 在主设备上通过 RDP 或 SSH 连接到远程电脑。
  4. 辅助设备（手机）：点击 Deskify 保管库中的作为辅助设备连接卡片。若没有该卡片，请点击设置 → 辅助设备 → 底部的“作为辅助设备连接”。
  5. 点击列表中显示的主设备名称。
  6. 主设备屏幕上会显示 6 位代码。在手机上输入该代码并点击配对。
  7. 选择主设备上的会话，然后选择此手机要担任的角色。
代码仅需输入一次。配对信息会保存在双方设备中，下次即使两台设备的角色互换也可以免代码连接。之后只需点击保管库中的卡片即可直接连接；如果只有一个打开的会话，将直接以你上次使用的角色启动。

角色

⌨️ 键盘 · 触控板RDP · SSH

无需遮挡平板屏幕，即可在手机上移动指针和输入文字。单指：移动，点按：点击，双指：滚动，双指点按：右键，长按：拖拽。通过按键栏和快捷键按钮进行输入。在 SSH 下，当屏幕上的程序（vim、tmux 等）捕获鼠标时，便会作为触控板使用。

🖥️ 副显示器RDP

远程 Windows 会新增一台手机大小的显示器，可直接将窗口拖动到手机屏幕上。点按：点击，拖动：滚动，长按：右键。按返回键可调出工具和按键栏：选择显示器位置（右侧、左侧、下方、上方）、缩放比例以及“按此屏幕尺寸重新调整显示器”。

✏️ 绘图板RDP

使用设备的手写笔在远程电脑上作画。压感、笔按键和橡皮擦均作为 Windows 触控笔输入传递。整个桌面映射到数位板上，可以在板上显示桌面的缩略图（也可以关闭）。没有手写笔时，用手指也可以绘制。

🖌️ 画笔面板RDP

以大按钮的形式操作绘图软件的快捷键：撤销、画笔大小、橡皮擦、画布平移等。可以调整按钮顺序、隐藏按钮，或添加自定义按键组合。

🔲 快捷面板 (Stream Deck)RDP · SSH · 电脑版中的“此电脑”

只需自定义一个大按钮，即可一键发送快捷键、文本、命令或启动程序。支持组合多步操作或用文件夹整理；如果电脑版为主设备，还能控制 OBS 并根据当前前台程序自动切换页面。

💡 会话助手SSH

在手机上显示命令帮助和执行结果查看；选中的命令会自动输入到主设备的终端中。

📂 文件SSH

在手机上浏览服务器文件夹。开启“跟随终端”可同步跟踪终端中的 cd 命令。可将点击的路径插入到提示符处，或直接 cd 到该目录。

🖥 第二个 ShellSSH

在同一个 SSH 连接中多打开一个 Shell 并显示在手机上：可以一边查看日志，一边在别处输入命令。

✨ AI 助手SSH

终端保留在主设备上，从手机向 AI 发出请求；命令会在主设备终端中执行。需要在主设备的“设置 → 实验室”中配置 Claude 或 Gemini 密钥（密钥仅保留在主设备上）。

🎮 电脑屏幕串流（测试）电脑版中的“此电脑”

将安装了 Deskify 电脑版的电脑屏幕通过显卡压缩后在手机上显示，并通过手机触控操作鼠标。

当电脑版作为主设备时，仅可选择副显示器、快捷面板 (Stream Deck) 和电脑屏幕串流。

切换角色 · 结束

  • 在手机上：点击顶部栏中的角色名称（⇄）即可切换到其他角色。点击 ← 离开会话（连接仍会保持）；若要彻底断开，请在保管库卡片中点击断开连接。
  • 在主设备上：在会话画面的 ⋮ → 辅助设备 中，可以为每台已连接的手机指定角色，副显示器的位置也在此处更改。
  • 移交会话：在主设备的 ⋮ → 辅助设备 中将会话移交至手机，或通过手机角色列表下方的“接管会话”来获取。密码不会被转移，接收设备将使用自身保管库中的凭据或显示登录窗口。（电脑版不支持移交会话。）

常见问题

手机列表中未显示主设备
  • 请确认两台设备是否确实处于同一 Wi-Fi 下；若有一方使用移动数据或其他路由器，将无法发现设备。
  • 访客 Wi-Fi 或路由器的 AP 隔离（无线设备间通信拦截）开启时，设备间将无法互相发现。请使用常规 Wi-Fi 或在路由器设置中关闭该功能。公司和咖啡店的 Wi-Fi 通常都会拦截此通信。
  • 请关闭手机和电脑上的 VPN；VPN 可能会拦截局域网内搜索设备的信号。
  • 请在主设备上保持 Deskify 打开，并确认已开启允许辅助设备。屏幕熄灭且处于休眠状态的设备不会响应。
  • 在 Android 17 上，两台设备均需要附近设备权限。
  • 对于之前配对过的设备，点击列表下方的“之前配对过的设备”即可尝试连接其最后的地址。
电脑版为主设备，但手机无法找到它
  • 请确认电脑版已登录且具有 Pro 权限，并且设置 → 移动设备 → 副显示器 已开启。
  • Windows 防火墙：首次启动弹出的提示中，必须允许 Deskify 在专用网络上访问。如果当时拒绝了，请在 Windows 安全中心 → 防火墙 →“允许应用通过防火墙”中勾选 Deskify。
  • 如果 Windows 网络配置文件为公用，可能会被拦截；请在“设置 → 网络和 Internet”中将其更改为专用。
  • 请关闭电脑上的 VPN。
提示代码错误或代码窗口消失
  • 代码为当前显示在主设备上的 6 位数字。输错 3 次将断开连接。
  • 代码仅可使用一次。如果在主设备上取消了操作，或因连接断开导致代码窗口关闭，请在手机上重新点击主设备以获取新代码。
  • 若提示“正在与其他设备配对”，请等待另一台手机配对完成后再试。
提示“名额已满”

主设备可连接的设备数量已达上限（订阅为 2 台，终身版/广告为 1 台，电脑版为 2 台）。请在主设备的“设置 → 辅助设备”（电脑版为“设置 → 移动设备”）中删除不使用的设备。

副显示器未出现
  • 远程 Windows 必须支持在会话中调整画面尺寸（显示控制）：需要 Windows 8.1、Server 2012 R2 或更高版本。
  • 如果远程电脑上的组策略将“限制最大监视器数”设置为 1，则无法添加显示器。
  • 每个桌面仅支持 1 台副显示器。如果另一台手机或 DeX 屏幕正在使用，请将其关闭。
  • 在电脑版上，仅支持在 Deskify 电脑版内部连接的远程桌面标签页中使用（Windows 自带的远程桌面窗口不支持）。
  • 若仍未出现：请在手机上按返回键 → 点击“按此屏幕尺寸重新调整显示器”，或重新选择角色。
按键或触控无效，并显示“已暂停”

输入类角色（键盘、副显示器、绘图板、快捷面板等）仅在主设备屏幕上显示该会话时才会工作，以防止误输入到看不到的电脑上。在主设备上打开该会话即可继续。当主设备开启应用锁时也会暂停。

提示“协助已关闭”/“安全连接失败”
  • 在主设备的“设置 → 辅助设备 → 已配对的设备”中，为该设备开启“允许此设备协助我的会话”。
  • 若安全连接（握手）失败，请在主设备上关闭并重新开启“允许辅助设备”，然后再试一次。
画面卡顿或模糊

副显示器画面通过 Wi-Fi 传输，网络繁忙时会自动降低画质和帧率（最高约 1.5MB/s）。靠近路由器并使用 5GHz Wi-Fi 可改善体验。若连接暂时中断，最长会在 5 分钟内自动重新连接。

使用限制

  • 仅支持同一 Wi-Fi（同一网络）；无法将跨互联网的设备作为辅助设备使用。
  • 支持 RDP 和 SSH 会话。不支持 VNC 会话。
  • 每个桌面仅限 1 台副显示器。
  • 电脑版作为主设备时：仅支持副显示器、快捷面板 (Stream Deck) 和电脑屏幕串流；副显示器的位置位于右侧或下方。
  • 主设备显示其他画面时，文件、第二个 Shell 和 AI 助手仍会继续工作；输入类角色则会暂停。
