  1. PC에서 설정 → 시스템 → 원격 데스크톱을 켭니다. (Windows Pro·Enterprise에만 있습니다. Home은 아래 질문을 보세요.)

  4. PC가 절전 중이면 깨운 뒤 다시 시도합니다(보관함 ⋮ → 켜기, Wake-on-LAN 설정 시).

I can't connect to my Windows PC
  1. On the PC, turn on Settings → System → Remote Desktop (Windows Pro/Enterprise only; for Home see below).
  2. Make sure the phone and the PC are on the same Wi-Fi. Away from home, see "Connecting from outside".
  3. The user name is the account you sign in to the PC with. For a Microsoft account, use the e-mail address and its password (not the PIN).
  4. If the PC is asleep, wake it and try again (vault ⋮ → Wake, when Wake-on-LAN is set up).

Windows Home이라 원격 데스크톱이 없어요

Windows Home은 원격 데스크톱(RDP)으로 접속받을 수 없습니다. 그 PC에 Deskify(Windows용)를 설치하고 같은 구글 계정으로 로그인하면, Deskify를 거쳐 PC 화면을 그대로 보고 조작할 수 있습니다.

  1. 폰 Deskify의 내 기기에서 그 PC를 누르고 보관함에 추가를 고릅니다.
  2. 이제 보관함 카드를 누르면 바로 연결됩니다. 카드에는 RDP 대신 Deskify와 베타 표시가 보입니다.
  3. 이미 RDP로 저장해 둔 컴퓨터라면, RDP가 응답하지 않을 때 나오는 Deskify로 연결을 누르세요.

RDP가 실제로 연결되는 PC는 그대로 RDP로 연결합니다. Deskify를 거치는 연결은 지금 모니터 화면을 그대로 공유하는 방식이라, PC 앞의 화면과 같은 화면을 보게 됩니다(구독 혜택 · 베타). PC 화면이 잠겨 있으면 PC Deskify의 잠금 화면에서도 쓰기를 켜 두세요.

Deskify를 설치할 수 없다면 VNC도 쓸 수 있습니다: PC에 TightVNC나 UltraVNC 같은 VNC 서버를 설치하고 비밀번호를 정한 뒤, 컴퓨터 추가 → VNC로 추가합니다.

My PC runs Windows Home (no Remote Desktop)

Windows Home can't accept Remote Desktop (RDP) connections. Install Deskify for Windows on that PC and sign in with the same Google account: you can then see and control its screen through Deskify.

  1. In the phone's My devices, tap that PC and choose Add to vault.
  2. Tap its vault card to connect. The card shows Deskify instead of RDP, with a beta mark.

Windows Home のためリモート デスクトップがありません

Windows Home はリモート デスクトップ（RDP）接続を受け付けられません。その PC に Deskify（Windows 版）をインストールして同じ Google アカウントでログインすれば、Deskify 経由で PC の画面をそのまま見て操作できます。

  1. スマホの Deskify のマイデバイスでその PC をタップし、保管庫に追加を選びます。
  2. 保管庫のカードをタップするとすぐに接続します。カードには RDP の代わりに Deskify とベータ表示が出ます。
  3. すでに RDP で保存している場合は、RDP が応答しないときに表示される Deskify で接続をタップします。

RDP が実際につながる PC はそのまま RDP で接続します。Deskify 経由の接続はモニターの画面をそのまま共有する方式なので、PC の前と同じ画面を見ることになります（サブスクリプション特典・ベータ）。PC がロックされているときは、PC の Deskify でロック画面でも使うをオンにしてください。

Deskify をインストールできない場合は VNC も使えます: TightVNC や UltraVNC などの VNC サーバーをインストールしてパスワードを設定し、VNCとして追加します。

잠금 화면(PIN)에서 키보드·마우스가 안 될 때

Windows 잠금 화면과 로그인(PIN) 창은 보안 화면이라, 일반 앱이 보내는 키와 클릭이 닿지 않습니다. 그래서 PC가 잠겨 있으면 화면은 보여도 입력이 무시될 수 있습니다.

  1. PC의 Deskify에서 설정 → 모바일 기기 → 화면 공유 원격 (Pro)의 "잠금 화면에서도 쓰기 (서비스 설치)"를 켭니다. 관리자 권한을 한 번 묻습니다.
  2. 그다음부터는 잠금 화면에서도 PIN을 입력하고 클릭할 수 있습니다.

이 설정을 쓰는 기능: 웹 Deskify의 이 PC 화면 보기, 폰 Deskify의 내 기기 → 화면 스트리밍(🎮 내 PC 스트리밍), 앱에서 여는 화면 공유.

  • PC 앱을 업데이트한 뒤 잠금 화면에서 다시 안 되면 이 설정을 한 번 껐다 켭니다.
  • 화면 스트리밍에서 폰 키보드로 친 글자는 잠금 화면에서 숫자·영문 키로 보냅니다. 잠금 화면에는 한글 입력기가 없습니다.

Keys and clicks don't work on the lock screen (PIN)

The Windows lock screen and sign-in (PIN) prompt run on a secure screen that ordinary apps can't send keys or clicks to. So while the PC is locked you may see it but your input is ignored.

  1. In Deskify on the PC, turn on "Also on the lock screen (installs a service)" under Settings → Mobile devices → Screen sharing (Pro). Windows asks for administrator rights once.
  2. From then on you can type the PIN and click on the lock screen.

Features that use this setting: View this PC's screen in Web Deskify, My devices → Stream its screen (🎮 Stream my PC) in the phone app, and screen sharing opened from the app.

  • If it stops working on the lock screen after a PC app update, turn the setting off and on once.
  • In screen streaming, what you type on the phone keyboard is sent as digit and letter keys on the lock screen (it has no IME).
  • Remote Desktop (RDP) connections don't need this: Windows asks for the sign-in itself when you connect.

ロック画面 (PIN) でキーボード・マウスが効かないとき

Windows のロック画面とサインイン (PIN) 画面はセキュリティ保護された画面のため、通常のアプリから送るキーやクリックが届きません。PC がロックされていると、画面は見えても入力が無視されることがあります。

  1. PC の Deskify で設定 → モバイル端末 → 画面共有リモート (Pro) の「ロック画面でも使う (サービスをインストール)」をオンにします。管理者権限を一度求められます。
  2. 以後はロック画面でも PIN の入力やクリックができます。

この設定を使う機能: Web 版 Deskify のこの PC の画面を見る、スマホ版 Deskify のマイデバイス → 画面ストリーミング (🎮 自分の PC をストリーミング)、アプリから開く画面共有。

  • PC アプリの更新後にロック画面で効かなくなったら、この設定を一度オフにしてからオンにします。
  • 画面ストリーミングでスマホのキーボードで入力した文字は、ロック画面では数字・英字のキーとして送ります (ロック画面には IME がありません)。
  • リモート デスクトップ (RDP) での接続にはこの設定は不要です。接続時に Windows が直接サインインを求めます。

在锁屏 (PIN) 界面键盘和鼠标无效

Windows 锁屏和登录 (PIN) 界面属于安全桌面，普通应用发送的按键和点击无法到达。因此电脑锁定时，即使能看到画面，输入也可能被忽略。

  1. 在电脑上的 Deskify 中，打开设置 → 移动设备 → 屏幕共享远程 (Pro) 里的“锁屏时也可使用 (安装服务)”。会请求一次管理员权限。
  2. 之后即可在锁屏界面输入 PIN 和点击。

使用此设置的功能：网页版 Deskify 的查看此电脑屏幕、手机版 Deskify 的我的设备 → 画面串流（🎮 串流我的 PC），以及从应用打开的屏幕共享。

  • 更新电脑版后如果锁屏界面又无法输入，请将此设置关闭再打开一次。
  • 屏幕串流中用手机键盘输入的文字，在锁屏界面会以数字和字母按键发送（锁屏界面没有输入法）。
  • 通过远程桌面 (RDP) 连接时不需要此设置：连接时 Windows 会直接要求登录。

Beta A subscription perk · still being polished.

My devices → Stream its screen (🎮 Stream my PC) in the phone app and View this PC's screen in Web Deskify have two ways to control the PC. Switch with the toolbar button.
