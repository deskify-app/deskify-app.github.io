Deskify는 Android용 원격 데스크톱(RDP)·SSH 클라이언트입니다. 폰, 태블릿, 데스크톱 모드(DeX)에서 Windows PC와 Linux 서버를 내 컴퓨터처럼 씁니다.

Deskify is a Remote Desktop (RDP) and SSH client for Android. Use your Windows PC and Linux servers from a phone, a tablet or desktop mode (DeX) as if you were sitting in front of them.

Deskify は Android 向けのリモート デスクトップ (RDP)・SSH クライアントです。スマホ、タブレット、デスクトップモード (DeX) から、Windows PC や Linux サーバーを自分のコンピューターのように操作できます。

Deskify 是一款适用于 Android 的远程桌面 (RDP) 与 SSH 客户端。可在手机、平板和桌面模式 (DeX) 上，像使用自己的电脑一样操作 Windows PC 和 Linux 服务器。

암호화해서 보관

Kept encrypted

暗号化して保管

加密保存

비밀번호와 SSH 키는 기기 안에서 암호화해 보관합니다. 동기화를 켜면 계정 전용 키로 암호화해 저장하고, 같은 계정으로 로그인한 내 기기끼리만 맞춥니다.

Passwords and SSH keys are encrypted on the device. With sync on, they are stored encrypted with a key made for your account and kept the same only across devices signed in to it.

パスワードや SSH 鍵は端末内で暗号化して保管されます。同期をオンにすると、アカウント専用の鍵で暗号化して保存され、同じアカウントでログインした自分の端末間でのみ同期されます。

密码和 SSH 密钥均在设备本地加密保存。开启同步后，将使用账号专属密钥加密存储，且仅在你登录了同一账号的设备之间保持同步。
